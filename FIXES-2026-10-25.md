# Crizon targeted bug fixes (2026-10-25)

Only targeted source changes were made in `src/app.js`:

1. **File download:** If Android's public Downloads write throws (including `FILE_NOTCREATED`), the app now attempts a WebView/browser download fallback instead of immediately failing. Native public-folder behavior still needs verification on the target Android build/device.
2. **Chat scroll jumping:** Firestore message snapshots now capture the prior scroll position. If the user is reading older messages, the view preserves that position as content re-renders; if already near the bottom, it follows new messages. Initial chat opening still scrolls to the latest message.
3. **Profile pictures:** Contact profile/name fields are refreshed instead of keeping the entire stale cached contact object. A live Firestore profile listener updates the chat list and the currently open chat header when a contact changes their profile picture/name.
4. **Offline chat list:** Cached rows are retained when offline contact lookups return no documents, avoiding replacement of a locally saved list with an empty list.

## Build

This repository archive did not include generated `www/app.bundle.js` or `www/native-bridge.js`. Build them after installing dependencies:

```sh
npm install
npm run build
```

For Android, then run the project's normal Capacitor sync/build process. A real Android device test is still required, especially for writing into the public Downloads folder, since Android version and WebView download handling vary.
